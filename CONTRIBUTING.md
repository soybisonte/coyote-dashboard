# Contribuir

Describe el síntoma, placa exacta, versión del core y resultado esperado.
Adjunta solo logs relevantes y elimina datos personales/configuración local.
Para un cambio, ejecutar `tools/verificar.py`, pruebas host y compilación de
las placas afectadas. Declara expresamente qué hardware sí probaste.

Conserva las copias de headers y las firmas de radio. No añadas pruebas que
activen relés ni publiques binarios/configuraciones particulares. Si cambias
montaje, contenido u orden, actualiza README, contexto y conexiones. Las
contribuciones de código/textos se proponen bajo MIT; los gráficos necesitan
una licencia o permiso propio y una indicación clara de procedencia.
